# 总结合并 & 字幕分句优化

**状态：** 待处理

---

## 1. 总结合并质量差

**现状：** `strip_timestamps` 只去掉时间戳，不做段落合并。输出仍是逐句断行：

```
我小时候也
种过地。但是我想告诉你,
有一些想法
锁死了你。
```

**目标：** 合并为连续自然段，保留段落间空行：

```
我小时候也种过地。但是我想告诉你，有一些想法锁死了你。...
```

**做法：** 加一个 `normalize_paragraphs` 步骤——相邻短句（< 20 字）连接成一行，句号/问号/感叹号结尾时不连接下一句。只有间隔超过 N 秒的段之间才保留空行。

---

## 2. 字幕分段过长

**现状：** 转写段落被原样翻译为字幕块，某些段长达 22 秒、几十字。字幕不是逐句切换，而是长时间贴一大段文字。

**目标：** 字幕按自然句切分，每段 2-5 秒，1-2 行。

**做法：** `segments_to_srt` 生成 SRT 之前，先按标点（句号/逗号/问号）拆分子字幕块。如果原文段落对应的时间段是 0s-22s，其中有 3 句话，则拆为 3 条字幕，时间轴按字数比例分配。
